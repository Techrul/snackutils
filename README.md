# Snackutils

Tiny utilities that could save you a few lines
[Github](https://github.com/Techrul/snackutils)
[PyPi](https://pypi.org/project/snackutils/)
## Install

```bash
pip install snackutils
```

## Utilities
Want a utility? Suggest it in [issues](https://github.com/techrul/snackutils/issues)!

| Function | What it does |
| --- | --- |
| `eight_ball()` | Returns a random magic 8-ball answer |
| `flip_coin()` | Returns `"Heads"` or `"Tails"` |
| `roll_dice()` | Rolls a six-sided die, returns 1 to 6 |
| `detect_os()` | Returns your OS name, like `"Windows"`, `"MacOS"`, or `"Linux"` |
| `average(a, b)` / `mean(a, b)` | Average of two numbers |
| `average_list(numbers)` / `mean_list(numbers)` | Average of a list of numbers |
